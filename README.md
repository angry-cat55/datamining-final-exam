# 서울시 상권 매출 예측 및 위기 상권 도출

서울시 상권분석 공공데이터를 통합하여 2024년 1~3분기 상권 데이터를 기반으로 4분기 상권별 추정 매출을 예측하고, 핀셋 지원이 필요한 위기 상권을 도출하는 데이터마이닝 프로젝트입니다.

## 프로젝트 목표

- 서울시 상권, 점포, 유동인구, 매출, 행정동, 소상공인 상가 데이터를 통합 분석
- 2024년 1~3분기 데이터를 이용해 4분기 매출 예측
- 회귀 모델 성능 비교
- 예측 매출 하락률과 절대 매출 규모를 함께 고려한 위기 상권 도출
- 지자체 정책 지원 방향 제안

## 프로젝트 구조

```text
datamining-final-exam/
└── final_project.ipynb
```

데이터 파일은 노트북 기준으로 다음 경로에 위치해야 합니다.

```text

```

## 사용 데이터

본 프로젝트에서는 다음 CSV 데이터를 사용합니다.

- 서울시 상권분석서비스 추정매출-상권 데이터
- 서울시 상권분석서비스 점포-상권 데이터
- 서울시 상권분석서비스 길단위인구-상권 데이터
- 서울시 상권분석서비스 영역-상권 데이터
- 서울시 상권분석서비스 영역-행정동 데이터
- 서울시 상권분석서비스 추정매출-서울시 데이터
- 소상공인시장진흥공단 상가정보 데이터

## 분석 과정

1. 데이터 로드 및 전처리
   - 2024년 분기 데이터 필터링
   - 상권, 점포, 유동인구, 영역, 서울시 평균 매출, 상가정보 병합
   - 결측치 평균 대체

2. 탐색적 데이터 분석
   - 시간대별 유동인구와 매출 관계 분석
   - 연령대별 유동인구와 매출 관계 분석
   - 주요 외식업종의 분기별 매출 비중 분석
   - 매출과 주요 변수 간 상관계수 확인

3. 비지도학습 기반 파생 변수 생성
   - PCA를 이용한 유동인구 변수 차원 축소
   - K-Means를 이용한 상권 군집화

4. Feature Engineering
   - 객단가
   - 유동인구당 매출
   - 주야간 매출 비율
   - 프랜차이즈 점유율
   - 서울 평균 대비 매출 비율
   - 상권 점포 밀도
   - 행정동 상가 밀도

5. 회귀 모델링
   - Linear Regression
   - Random Forest Regressor
   - Gradient Boosting Regressor
   - GridSearchCV 기반 하이퍼파라미터 튜닝

6. 위기 상권 도출
   - Q4 예측 매출이 Q1~Q3 평균 대비 하락한 상권
   - 동시에 절대 매출 규모가 낮은 영세 상권
   - 두 조건을 모두 만족하는 상권을 위기 상권으로 분류

## 모델 성능

매출 직접 변수로 인한 Data Leakage를 방지하기 위해 절대 매출 금액 및 매출 건수 관련 변수는 최종 모델 입력에서 제외했습니다.

| Model | RMSE | R2 |
| --- | ---: | ---: |
| Linear Regression | 약 65.71억 원 | 0.6014 |
| Random Forest | 약 73.03억 원 | 0.5076 |
| Gradient Boosting | 약 65.60억 원 | 0.6027 |

최종 분석에서는 앙상블 모델 중 가장 높은 성능을 보인 Gradient Boosting 모델을 중심으로 해석을 진행했습니다.

## 정책적 시사점

위기 상권은 유동인구 대비 매출 효율이 낮고, 서울시 평균 대비 매출 경쟁력이 낮으며, 프랜차이즈 점유율과 상업 집적도가 상대적으로 낮은 특성을 보였습니다.

이에 따라 다음과 같은 핀셋 지원 정책을 제안합니다.

- 지역화폐 연계 소비 촉진 쿠폰 제공
- 야간 경제 활성화 프로그램 운영
- 앵커 점포 유치 및 소상공인 마케팅 지원
- 연령대별 유동인구 특성을 고려한 타겟 마케팅 지원
- 공실 활용, 팝업스토어, 창업 지원을 통한 상권 집적도 개선
